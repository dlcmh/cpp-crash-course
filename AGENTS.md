# AGENTS.md

Guidance for AI coding agents working in this repository.

## Permissions

- You may autonomously commit and push to this repo without asking for confirmation.

## Conventions

- Record any new standing decisions (permissions, conventions, tooling choices) as a dated row in `DECISIONS.md`.
- Commit messages: short imperative summary line, e.g. "Add .gitignore for macOS/C++ and DECISIONS.md log".

- C++ project developed on macOS; `.gitignore` covers macOS metadata and C++/CMake build artifacts.
